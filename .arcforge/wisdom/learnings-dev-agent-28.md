
## dev-agent-28 / TASK-002（V 的类别维度 EPS）

### 1. 「对照组」是把假设升级成机制的那一步
派单假设是「companyfacts 聚合视图漏了维度」。我查到 V 的 EPS 100% 带 StatementClassOfStockAxis
维度——但这只证明了「EPS 有维度」，没证明「companyfacts 因为有维度才丢它」。
真正定案的是**对照组**：同一份文档里 NetIncomeLoss **有**无维度版本，且它在 companyfacts 里
有 227 条。有了这一条，「只收无维度事实」才从假设变成被证明的机制，同时排除了
「V 根本没申报 EPS」这个竞争解释。**下次遇到「A 缺失是因为 B」，先找一个同环境下 B 不成立、
A 却存在的样本。**

### 2. 指标达成 ≠ 目标达成（我差点静默通过）
DoD 写的是「0 degraded」。我实现完确实 0 degraded 了——但顺手查了估值覆盖，发现
370 天 / pctl_5y 118 点，**比它替换掉的 engine 兜底（705/453）还短**。
如果只看 DoD 那一行，这次交付会是「达标但让用户可见的历史腰斩」。
**在报「达标」之前，多查一个「用户实际拿到什么」的指标。**

### 3. 结论对自己有利时，仍然要去验证
我给代码写了句注释断言覆盖率改善（"恢复到 1054 天/802 点"）——**在测量之前**。
重跑 live 显示**毫无变化**（371→370）。没有任何机制会强制我去核这句话：它对我有利、
藏在注释里、没人会去跑。**自己写的、对自己有利的、没人会核的陈述，是最需要主动验证的一类。**
顺带把「我的路径有问题」和「整个数据源就这样」区分开了：那约一年的 filing-date 滞后是
既有且跨公司的（companyfacts 自己的对比期条目也带），不是我引入的。

### 4. 「现象 → 机制」比「试试看」值钱
把「370 天」追到 ttmPoints 用**窗口末季**的 FilingDate 打戳、effectiveDate 按它 gating，
并**排除**了两个更自然的怀疑对象（EPS 起点、价格起点，都不绑定）。
做完这一步，「提高上限能改善多少」就从赌博变成可预测——实测 1377 天正好落在预期上。

### 5. 变异存活先查证再归类（AD-27 的实战复现）
首轮 M1/M3/M4 存活。**都不是等价变异**，而是「真实数据恰好覆盖不到该判定」——
实测 V 三份文档里 EPS 引用的 12~16 个 context 全部单维且落在类别轴，于是轴匹配、
候选过滤这些分支从不被触发。
其中 M4「return members[0]」**直接穿过了我的排列不变性用例**：V 的正确答案
CommonClassAMember 恰好也是字母序第一，排序后取首个与排列无关，同样满足不变性。
这是 TASK-001 同款陷阱的变体：**正确值与朴素实现的输出巧合相同**。
补救靠构造「正确答案不在字母序首位」的场景（Class Z 股本远大于 Class A）。

### 6. 在测不到的地方，不要动共享状态
提高回看上限时，maxSegmentFilings 是与分部营收共用的常量。抬高它会连带放大分部拉取量，
而那条路径在本任务 live 环境里 **segment_revenue 两次都是 0 行 ⇒ 无法测量**。
故新增独立常量 maxClassEPSFilings。**「我推断没影响」和「我测过没影响」必须分开说**，
在只有前者的时候，选不碰共享状态的那条路。

### 7. 常量要写清楚它是「硬边界」还是「可调参数」
28 不是拍的：reportDate ≤ 2019-03-31 的实例文档**全部 404**（老式非 inline XBRL），
40 份里可用的恰好 28 份。没有这句注释，后人会以为它可调，改成 50 然后困惑于多拉的都失败。

### 8. 回归告警要先证伪再采信
live 比对发现 WMT 有一处末位浮点差，看起来像回归。**同一个二进制三次运行分别产出
...333/...334/...334** ⇒ 是 Q4=FY−ΣQ 求和顺序取自 map 迭代序的既有抖动
（golden 早已为此约定 12 位有效数字）。按 12 位口径四家逐值一致。
**「两次运行结果不同」的第一嫌疑人是被测系统自身的不确定性，不是你的改动。**

### 9. 工具类教训
- fixture 用自建 extract 工具从真实文档**逐字节原样截取**（根元素+units+被引用 context+
  事实元素），再用独立 probe 复核提取件与原件逐值一致。手工编造的 fixture 无法证明真实结构，
  变异测试对该形态无效（AD-27 第六类）。
- **写通道内容一律走 stdin**，`--file` 不存在：我第一次用 `--file` 导致命令挂起等 stdin。
- code-simplifier 第四次留下半成品（本次：加了个与既有函数重名的 readFixture 致测试包不可编译，
  且 `go build` 通过、只有 `go vet` 会挂）。**不采信自述，用变异 harness 的 sha256 快照直接
  diff 产品代码**；且它改过代码后**变异必须整套重跑**。
