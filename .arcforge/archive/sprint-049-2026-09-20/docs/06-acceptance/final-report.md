### 4.1 TASK-010 discovery 里的一句假声明（裁决：真实缺陷，不构成 DoD 违反）

| 写法 | 读者会得到的印象 |


### 8.1 第 10 条的实测细节（dev 在 `89dc94e` 上建临时树验证，探针树已拆）

```
MigrateBitemporal        err=<nil>  AlreadyMigrated:true          ← 独立复审报的那一重

```

- **第二重**：`verifyBitemporalShape` 只匹配 `PRIMARY KEY (ts, indicator, fetched_at)` 字符串，
  **只验主键形状、不验列是否齐全** ⇒「三段主键但缺列」的库进 `atlas crisis *` 全族畅通无阻。
- **第三重**：`tablesDDL` 用 `CREATE TABLE IF NOT EXISTS`，对已存在的表是 no-op
  ⇒ **跑多少次都补不回那一列**，没有任何「重新初始化」能修复它。

🔴 **可达性比 QA 的 F7 更高**：一条 `ALTER TABLE macro_observations DROP COLUMN <x>`（sqlite 3.35+）
就能造出该状态，而**运维手工清理一个不再需要的列是完全正常的动作**。
（dev 排除了另两条路径：回滚会回到两段主键；迁移中断是单事务整体回滚。）

🔴 **成因形状值得单记**：`verifyBitemporalShape` **自己的错误文案里就写着
`CREATE TABLE IF NOT EXISTS does not change it`** —— 作者知道这个事实，
**但只把它用在「主键」维度，没用在「列」维度**。知识在场，而其适用范围被无声地限定在首次想到它的那个维度上。

### 9.1 判据七：证据已齐，且比判据要求的更强

在生产库**快照**上只读采样（`cp` 后 sha256 与源一致，生产库未被打开）：

| 采样元数据 | 值 |
| --- | --- |
| **采样时刻（UTC）** | **`2026-09-19T16:03:23Z`** |

| 快照大小 | 8179712 bytes |

🔴 **下面每个数字只在上表那一刻成立。复核前先跑 `SELECT MAX(fetched_at)`**：
已前移则数值必然不同 —— 那是数据增长，不是结论有误。

| 判据七原文的命令 | 门槛 | 实测 | |
| --- | --- | --- | --- |
| `count(*) from macro_observations` | > 31092 | **31508** | ✓ |
| `count(*) ... group by ts,indicator having count(*)>1` | **> 0** | **205** | ✓ |

**但那条 SQL 问的不是它想问的性质。** 205 个重复键里：

| | 键数 |
| --- | --- |
| 同值重抓（`count(distinct value) = 1`） | **204** |
| 🟢 **真修订**（`count(distinct value) > 1`） | **1** |

真修订那一条，逐行列出（不是聚合数）：

```
ts          indicator  value             source  fetched_at
2026-09-17  usdjpy     155.688003540039  yahoo   2026-09-17T14:45:05.515411000Z   ← 9/17 首次采到
2026-09-17  usdjpy     156.128997802734  yahoo   2026-09-19T14:45:03.331837000Z   ← 9/19 数据源修订了该日值
2026-09-17  usdjpy     156.128997802734  yahoo   2026-09-19T15:45:04.416247000Z   ← 再抓，未再变
```

`v_macro_current` 取到 `156.128997802734`（最新版）✓。
**旧值 `155.688003540039` 仍在库里** —— 在迁移前的 `INSERT OR REPLACE` 下，它会被永久覆盖。
⇒ **这是本次迁移价值的第一个真实生产证据，不是构造出来的。**

🔴 **顺带查出判据七那条 SQL 本身的精度问题**：它数的是 `count(*)>1`，会被**同值重抓**满足。
本次若那 1 个真修订不存在，它仍会报 **204 > 0** 而"通过"，**而实际没有任何修订被保住**。
