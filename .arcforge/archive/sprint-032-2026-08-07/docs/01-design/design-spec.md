## 零、本 Sprint 的风险画像

回归面为零（只新增包），所以**唯一的风险是「测试看起来齐全但守不住」**。
Sprint 031 在这一类上栽过至少八次，形态各异：

| 形态 | 031 实例 | 本 Sprint 的对应风险面 |
|---|---|---|
| 断言恒真（空真） | crypto 亚秒偏移遇上秒级键 | 注入用例若断言的是「有 error」而非「哪种 error」 |
| **纯函数守护 ≠ 行为守护** | tushare `callKey` 有单测、有聚合度断言，**唯独没人验「缓存槽真的用了它的输出」** | **`correlate`/`checkKey`/`zero` 全是纯函数，Task 1 的测试断言的是它们的返回值** |
| 断言对什么都敏感 | E1 红但不知是否只对该改动红 | 四种 Verdict 若共用一个断言 |
| 判定顺序 | 有效性判定写在行为断言之前 ⇒ 缺陷伪装成测试构造失败 | `bothShapes` 并行跑时的失败归属 |
| 缺席不举手 | 某测试从没被任何变异打中 | 六个任务九个文件，谁没被打过很难看出 |

## 一、必须写进 DoD 的五条（本 Sprint 特有）

### T1 纯函数守护必须配一条行为守护（教训 44）

`correlate` 的 `TestCorrelate` 断言的是**字符串相等**——那证明「函数会拼对」，
**不证明「Query 真的用了它拼出来的东西」**。

⇒ Task 4 必须有一条测试，在 **Spec 的业务键改变时** `CurrentQuery` 的行为随之改变
（而非只看 SQL 串）。判据：**改 `correlate` 的实现（如把 `AND` 换成 `OR`），
Task 4 的真 SQL 测试必须转红**——只红 `TestCorrelate` 说明 Query 没真正用它。

### T2 注入防护的断言必须指向「被拒」而非「有错」

`TestNewSpecRejectsInvalidIdentifiers` 用 `require.Error` ——**任何原因的 error 都满足它**。
若将来 `NewSpec` 因为别的原因（如 table 名太长）先行返回错误，注入那条也照样绿。

⇒ 判据：**至少对一个注入用例断言 error 信息含被拒的那个标识符**，
或断言错误类型/哨兵。**这是「对某个改动敏感 ≠ 只对该改动敏感」在负路径上的形态（教训 50）。**

### T3 `bothShapes` 并行跑必须能指出是哪套形状失败（教训 45）

两套 Spec 形状共用断言时，失败信息若不含形状标识，
**红了也不知道是 hestia 形状还是 crisis 形状的问题**。

⇒ 判据：`t.Run(shapeName, ...)` 子测试命名，或断言消息带形状名。

### T4 SQL 无字面值那条是唯一的字符串断言，它必须真的能红（C7 的例外）

`TestQueriesContainNoLiteralValues` 是文档明确允许的唯一字面量断言。
**但「不含字面值」是否定断言——未实现时天然成立。**

⇒ 判据：**造一个把业务键取值直接拼进 SQL 的变异，该测试必须转红**。
不能只验「当前实现下它绿」。

### T5 零值 `Spec` 是唯一绕过校验的途径，它的守护要覆盖所有入口

`Spec{}.zero()` 在 Task 1 定义、Task 5 使用（`TestLookupRejectsZeroSpec`）。
**但 `CurrentQuery`/`AsOfQuery`（Task 4）没有对应的零值检查测试。**

⇒ 判据：Task 4 须明确「零值 Spec 传入 Query 时的行为」——是 panic、返回空串、
还是文档声明「调用方保证非零值」。**三种都可接受，但必须有一条测试或注释钉住它**，
不能是未定义行为。（教训 41：沉默的排除等于没有排除。）

## 二、通用取证纪律（031 结转，逐条可执行）

1. **按 DoD 原文注入变异**（教训 30）——「我验过它会红」≠「它满足了判据」
2. **变异靶不存在即失败**（教训 39）——用 `assert old in s` 而非静默 `sed`
3. **拿到预期中的红时，问「它红的是不是我以为的那个原因」**（教训 28 补充）——
   本 Sprint 高危：编译失败的红、`require.Error` 吞掉的红
4. **变异记录要能反查**（教训 49）——「X 被哪些变异打中」而非「Y1 → 红了 X」，
   否则「某条测试从没上榜」发现不了
5. **四坐标自查**（031 结转第一条）：方向、强度、机制 + **范围**
   （「这条判据该覆盖几处，实际覆盖了几处」）
