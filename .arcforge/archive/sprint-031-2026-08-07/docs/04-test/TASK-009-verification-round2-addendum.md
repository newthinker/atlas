| | **M1c 归一化消费者**（`if IsNaN(v) { v = 0 }`） |


### 右下格是关键

它证明**探针本身有区分能力** —— 左上格的绿不是「探针测不出东西」。缺了这一格，
左上格的 ✓ 与「探针写错了、什么都没测」在输出上同样无法区分。**这与陷阱 10 同族**：
不是缺陷伪装成测试失败，而是**「无害」与「测不出」伪装成同一个绿**。

> 附：退回不深拷贝时既有 26 个测试**也 FAIL**（`TestCachedRowsAreIsolatedFromCallers` 捕获），
