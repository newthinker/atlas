## 4. 交叉验证 dev 的一个实测数字：**它对，但小样本偏低**

dev 在注释里写：把 `runs` 降到 1 并施加 M4 后，「该变异只在 **32/40** 次运行里被检出……
**并非直觉上的 50%**；Go 对 2 元素 map 的迭代起点并不均匀。这个数字是测出来的，不是推出来的」。

**它的定性完全正确**（不是 50%），我用 20 万次直接采样测了真值：

```
n=2 平票：变异被检出 87.57%（存活 12.43%）
我在 TASK-010 坐实的 (9−n)/8 模型预测 = 87.5%
```

- **真值是 87.5%**，dev 的 32/40 = 80% 是 40 次小样本估计（p=0.875 时 sd≈5.2%，80% 落在 1.4 个标准差内，**统计上完全相容**）；
- 模型 `P(插入序) = (9−n)/8` 在 n=2 处再次得到验证（此前已在 n=3/5/8 验过）；
- **它的结论不受影响**：无论 80% 还是 87.5%，单次调用都会放过约一到两成，循环是必须的。
